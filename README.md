# FastAPI RBAC Auth Service

Готовый шаблон (boilerplate) бэкенд-сервиса на FastAPI с реализацией системы контроля доступа на основе ролей (RBAC).

## 🚀 Основные возможности
* **JWT Аутентификация** — регистрация и вход пользователей.
* **Гибкий RBAC** — управление доступом через таблицы БД.
* **Проверка владения** — автоматическая проверка прав на редактирование/удаление собственных записей (`owner_id`).
* **Initial Data** — автоматическое заполнение базы данных базовыми ролями и администратором при первом запуске.

## 🛠 Технологический стек
* **Framework:** FastAPI
* **DB:** PostgreSQL + SQLAlchemy
* **Environment:** Docker / Docker Compose

## 🔐 Схема управления доступом

Система проверяет права в следующем порядке:


| Условие | Результат | Примечание |
| :--- | :--- | :--- |
| Авторизация не требуется | ✅ РАЗРЕШЕНО | Публичные эндпоинты |
| Пользователь заблокирован (`is_active: False`) | ❌ ОТКАЗ | |
| Роль пользователя — `admin` | ✅ РАЗРЕШЕНО | Полный доступ ко всему |
| Доступ к системным таблицам (Role, AccessRule) | ❌ ОТКАЗ | Запрещено всем, кроме админа |
| Глобальное право (`_all_permission`) | ✅ РАЗРЕШЕНО | Доступ ко всем записям типа |
| Личное право (`_permission`) + `create` | ✅ РАЗРЕШЕНО | Право на создание |
| Личное право + `read/update/delete` | ✅/❌ | Доступ только если `owner_id == user.id` |

## 📦 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd fastapi-rbac-auth
   ```

2. **Запустите проект через Docker:**
   ```bash
   docker-compose up
   ```

3. **Документация API:**
   После запуска Swagger доступен по адресу: [http://127.0.0](http://127.0.0)

4. **Панель управления БД (Adminer):**
   Доступна по адресу [http://localhost:8085/](http://localhost:8085/)
   * **Login:** `admin@admin.com`
   * **Password:** `root`
